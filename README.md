# BBT — Black Box Thinking

Simple internal Rulebook and learning system.

Stack: React + Vite + Supabase + Vercel.

## Setup
npm install
copy .env.example .env.local
npm run dev

Run `supabase/schema.sql` in the BBT Supabase SQL Editor.

Never put a Supabase secret/service-role key in the frontend or Git.
